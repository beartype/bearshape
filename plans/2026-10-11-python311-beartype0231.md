# Adopt Python 3.11 and beartype 0.23.1 coherently


This living ExecPlan follows `PLANS.md` and milestone M1 of `plans/2026-10-11-release-readiness.md`, which supplies the full release contract and audit context.

## Purpose / Big Picture


Users and developers should install and validate the same released dependency combination. Require Python >=3.11 and beartype >=0.23.1,<0.24, test exact 0.23.1 on supported Python 3.11–3.14, and preserve every existing backend and checker lane. This is the owner's explicit baseline decision, not a claim that released beartype fixes union rollback.

## Context and Orientation


`pyproject.toml` owns package dependency/interpreter metadata and three checker defaults. `ty.toml`, `ruff.toml`, `.python-version` and `.pre-commit-config.yaml` provide other defaults. `tox.toml` names interpreter/dependency/backend combinations; `tools/validate_tox_env.py` rejects invalid names, and `tools/validate_runtime.py` checks installed modules. `.github/workflows/validate.yml` is reused by CI/nightly/candidates. `tools/check_installed.py` tests the normal wheel outside source; `tools/smoke_minimal.py` proves optional dependencies are absent. Docs snippet parsing lives in `tools/check_docs.py`.

## Plan of Work


Replace current 3.10 floor references with 3.11, remove the redundant 3.10 entries rather than duplicating 3.11, and rename bt023rc0 tox factors to bt0231. Canonicalize both sides of origin comparisons. Update contributor/tool/installation/agent guidance and the current handoff summary and badge; keep dated evidence intact.

## Concrete Steps


From this worktree, with uv 0.11.17 on PATH:

    uv lock --upgrade-package beartype==0.23.1
    uv sync --locked
    uv run --locked prek install
    uv run --locked pytest tests/ --ignore=tests/test_typecheck.py -n auto
    uv run --locked pytest tests/test_typecheck.py -q
    uv run --locked tox run -e py311-bt0231-numpy22,py311-bt0231-jax05,py311-bt0231-torch26,py311-bt0231-optree014
    uv run --locked prek run -a
    uv run --locked prek run actionlint -a --stage manual

Repeat source/checker tests in a separate Python 3.14 environment. Installed archive and full hosted matrix evidence will also be refreshed on the final integration branch.
